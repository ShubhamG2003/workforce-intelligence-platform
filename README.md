# AI Workforce Analytics Dashboard

An AI-powered workforce analytics system that tracks employee productivity, burnout risk, and behavioral anomalies using real-time data.

---

## 🚀 Features

- KPI dashboard (work hours, breaks, late days)
- Burnout risk scoring system
- AI anomaly detection (Isolation Forest)
- Shift-wise analysis
- Time-based workforce trends
- Interactive Streamlit UI

---

## 🧠 AI Components

- Burnout scoring model (rule-based + weighted features)
- Anomaly detection using Isolation Forest
- Feature engineering on attendance behavior

---

## 📊 Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- PostgreSQL
